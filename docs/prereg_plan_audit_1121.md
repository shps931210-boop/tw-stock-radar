# 事前登記：網站上的買賣訊號本身有沒有贏 0050（2026-11-21）

這份文件在跑結果之前先提交。這次不發明新規則，而是**檢查網站現在真的顯示給使用者的結論**（app/buyplan.py）過去表現如何。

## 為什麼做這個
11/18 上線的「現在能不能買？」卡片把 AI 分數、本益比位置、波段訊號組合成結論，但組合本身從來沒有被整體回測過，網站只寫「可信度：尚未證明」。
11/18 的交易規則研究只測過「波段＋分數 ≥ 60」（−0.15，沒過），沒有加上本益比，也沒有測長期分批買進。

## 檢查的訊號（照 buyplan.py 現在的規則）
波段（每一筆波段進場訊號，出場用現行波段出場規則；和 `trade_rule_study` 同一套成交、成本、0050 基準）：
- **S-BUY 可以考慮進場**：均衡型分數 ≥ 60，且本益比在自己近兩年的位置 < 70%（沒有歷史區間的照網站規則不擋）。
- **S-WAIT 好公司等價格回落**：分數 ≥ 60，本益比位置 70%～85%。
- **S-AVOID 先不要買**：分數 < 45，或本益比位置 ≥ 85%。

長期（每 20 個交易日檢查一次，符合的股票等權買進，持有 120 個交易日，開盤到開盤）：
- **L-BUY 可以考慮分批買進**：財務品質 ≥ 60、成長能力 ≥ 60、均衡型分數 ≥ 60、本益比 ≤ 自己近兩年中位數、股價不低於年線 10%。

分數用當時資料重算（`pit_backtest.scored_rows`，和網站同一套程式）；本益比用當時已公布的近四季 EPS 與實際股價，位置以前 500 個交易日計（和 `valuation.band` 相同，至少 120 天）。

## 判定（和 11/18 交易規則研究相同門檻）
- 開發期（訊號日 < 2025-01-01）每月平均超額 > 0 且 t ≥ 2.6；開發期前後兩半都 > 0；保留期 > 0。
- L-BUY 持有期互相重疊，t 值用 Newey-West（落後 5 期）。
- S-AVOID 是警示：如果它的超額**顯著為負**（t ≤ −2.6）才算「警示有用」。

## 會改什麼（事先決定）
- 不論結果，個股卡的「可信度」改成顯示這個訊號**過去實際贏或輸 0050 多少**，取代籠統的「尚未證明」。
- S-BUY 或 L-BUY 沒過：卡片明寫「過去沒有贏 0050」，結論措辭降一級（例如「條件符合，但這套規則過去沒贏 0050」）。
- 通過：只寫「歷史上通過」，前瞻結果要另外累積，不宣稱證明有效。
