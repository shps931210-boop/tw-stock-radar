# 新聞與題材催化：資料規格（V21.2，2026-10-28）

狀態：**規格，尚未實作評分**。新聞不會進正式分數，要等有歷史資料可以驗證之後再說。

## 現況

| 資料 | 表 | 期間 | 能不能拿來回測 |
|---|---|---|---|
| 個股新聞（標題、摘要、來源、時間） | `news_items` | 2026-10-11 起，4,388 筆 | 不能：不到 3 週，沒有到期結果 |

月營收驚喜就是目前唯一驗證過的「題材催化」：每月 11 日起公開，有完整歷史。

## 每一筆事件要記錄的欄位

| 欄位 | 說明 |
|---|---|
| `event_id` | 來源＋公司＋時間的唯一鍵 |
| `stock_id`、`related_ids` | 主要公司；同產業或供應鏈受影響的公司 |
| `published_at` | 來源上的公告時間（到分鐘） |
| `fetched_at` | 我們實際抓到的時間。回測只能用 `fetched_at` 之後的價格 |
| `source_type` | 官方公告（公開資訊觀測站重大訊息、證交所、櫃買）／公司新聞稿／媒體報導／評論／傳聞 |
| `source_url` | 原文連結；沒有可信來源就不收 |
| `category` | 營收、訂單、產能、財報、法說會、併購、政策、訴訟、處置／注意股 |
| `fact_level` | 已確認事實／公司預測／分析師評論／傳聞 |
| `quant_impact` | 能不能換算成營收、毛利或 EPS 的影響；不能就填空，不猜 |
| `horizon` | 短期（1～5 日）／波段（20～60 日）／中長期 |
| `pre_move` | 公告前 5 日、20 日股價已經漲跌多少（衡量市場是否已反映） |
| `invalidation` | 什麼情況代表這個題材不成立（例如下個月營收沒有跟上） |

## 驗證計畫（事前登記後才做）

1. **先累積資料**：每天把公開資訊觀測站重大訊息、證交所與櫃買公告存進 `events`（免費，GitHub Actions 抓取）。研究任務 RT-20261028-023。
2. **事件研究**：等每一類至少有 100 筆、到期滿 20 日，再比較「官方確認」和「媒體或傳聞」公告後 5、20 日的超額報酬，扣成本，並控制公告前漲幅。
3. **增量檢查**：事件訊號要在控制投資價值、進場機會、月營收驚喜之後仍有預測力，才可以加進說明。加進正式分數則要過模型層級門檻，並由你同意。
4. **禁止事項**：
   - 不因為新聞字面上是正面就加分。
   - 沒有來源的消息不收。
   - 回測不得使用 `fetched_at` 之前的價格。

法人買賣超只從 2026-08 開始。要研究「外資 × 市況」，需要先用 FinMind 免費額度回補 2019 年後的三大法人資料。研究任務 RT-20261028-024。
