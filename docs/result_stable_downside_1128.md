# 結果：穩健型抗跌改善（2026-11-28）

事前登記：`docs/prereg_stable_downside_1128.md`（commit 0a3fb3a，先登記後執行）。資料到 2026-11-27，89 期（開發段 67、保留段 22），每期 20 個交易日，扣成本，基準 0050。

和現行比：沒有一個 t 接近 2.3（最高 0.19），保留段只有 RW 比現行好但它下跌期更差。

## 學到什麼

1. 穩健型過去其實有抗跌：0050 下跌的期數平均贏 0050 1.5～1.9 個百分點。11/17、11/18 那兩批是例外，不是常態。
2. 它輸 0050 是輸在上漲期（保留段平均每期少 7 個百分點）。2025 年起 0050 大漲，穩健型跟不上。
3. 加 Beta 篩選確實更抗跌（最大回撤從 −31% 降到 −19%），但上漲期輸更多，加起來一樣，沒有真的變好。
   低 Beta 只是「少跌也少漲」，不是選股能力。
4. 所以要贏 0050 不能只靠更保守，下一步要找在上漲期也跟得上的方法；而且 2019 年起連全部股票等權都輸 0050（台積電權重太大）。

網站與正式選股都不變。
