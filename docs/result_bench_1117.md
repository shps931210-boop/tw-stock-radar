- 做法 B：近似誤差可接受（B0 − 0050 平均 −0.22、相關 0.99）。在前 50 大裡加重高分股，比不調整的 B0 多：開發段 +0.14～+0.35（t 1.6～2.1）、保留段 +0.02～+0.18（t < 0.7）。方向一致是正的，但保留段太小不顯著，而且被 B0 本身落後 0050 的 0.49 吃掉。
- 依登記規則：全部不採用，正式選股不變。
- 後續（新的事前登記，不是這次結果的一部分）：直接持有 0050 再用成分股分數做小幅加減碼，只做影子前瞻紀錄。
