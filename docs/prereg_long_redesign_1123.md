# 事前登記：長期買進條件重新設計（2026-11-23）

這份文件在跑結果之前先提交。結果另外提交在 `docs/result_long_redesign_1123.md`。

## 為什麼
11/21 回測（`docs/result_plan_audit_1121.md`）發現網站長期結論「四項條件都符合」（品質、成長、分數 ≥ 60，本益比 ≤ 自己兩年中位數，不低於年線 10%）
持有 120 個交易日平均輸 0050 5.30 個百分點，比隨便買還差。推測原因是「價值陷阱」：本益比變便宜常是市場預期獲利要下滑。
這次只測一個想法：**把「本益比比過去便宜」換成「獲利和營收現在還在成長」**。

## 共同條件（所有候選都要）
- 財務品質 ≥ 60、成長能力 ≥ 60、AI 均衡型分數 ≥ 60（和網站同一套，用當時資料重算，`plan_audit` 的 88 期分數）。
- **獲利成長**：當時已公布的近四季 EPS 合計 > 0，且比四季前（同樣已公布）的近四季 EPS 合計高。
- **營收成長**：當時已公布的最近 3 個月營收合計，比去年同期 3 個月合計高。

## 候選（3 個，只有這 3 個）
| 代號 | 共同條件之外 |
|---|---|
| G1 | 不看估值 |
| G2 | 本益比不高於自己近兩年第 80 百分位（只排除過熱，不要求便宜） |
| G3 | 收盤價在年線（240 日均線）之上 |

## 交易
每 20 個交易日檢查一次（和 11/21 同一套期間），符合的股票等權，隔天開盤買、持有 120 個交易日後開盤賣，扣成本（`trade_rule_study.COST`）；包含已下市股票。對 0050 同一段開盤到開盤。

## 門檻（和 11/21 相同，全部要成立）
1. 開發期（< 2025-01-01）平均超額 > 0，Newey-West（落後 5 期）t ≥ 2.6。
2. 開發期前後兩半都 > 0。
3. 保留期平均超額 > 0，**而且保留期贏 0050 的期間比例 > 50%**（11/21 長期結論保留期平均贏但只有 31% 期間贏，平均數被少數期間拉高，這次多加這一條）。

## 通過或沒過之後
- 有通過：只把網站長期結論的條件換成通過的那一個，卡片寫「歷史上通過、前瞻尚未證明」，並開始前瞻紀錄；不宣稱證明有效。
- 都沒過：網站長期結論維持「四項條件都符合／過去沒贏 0050」，照實記錄失敗，不調參數重跑。
